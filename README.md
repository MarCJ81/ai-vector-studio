# 원탭 벡터 스튜디오 (One-Tap Vector Studio)

AI(ChatGPT·미드저니·파이어플라이 등)로 만든 **로고·일러스트·아이콘 PNG/JPG**를
**인쇄용 초정밀 벡터**로 바꾸는 정적 웹앱입니다.

- 배경 자동 투명화 → 색상 양자화 → 잡티 제거 → 서브픽셀 윤곽 → 베지어 피팅 → 용량 최적화
- 내보내기 4종: **SVG · EPS(PostScript Level 2) · AI(PDF 호환) · PDF 1.4**
- **서버 없음.** 이미지는 브라우저 밖으로 나가지 않습니다. 빌드 도구도 없습니다.

```
python3 -m http.server 8000     # 이 폴더에서
# → http://127.0.0.1:8000/
```

---

## 1. 왜 만들었나

AI가 만든 로고는 대부분 1024×1024 PNG입니다. 명함(300dpi)에 쓰려면 3,000px 이상이 필요하고,
현수막은 그보다 더 큽니다. 확대하면 계단이 보이고, 인쇄소는 벡터(EPS·AI)를 요구합니다.

이 앱은 **픽셀을 버리고 수학으로 다시 그립니다**. 결과는 확대해도 깨지지 않고,
용량은 원본 PNG의 수십 분의 일입니다.

| 항목 | 예시 (400×400 3색 엠블럼) |
|---|---|
| 생성된 앵커 노드 | 120개 (원본 윤곽 점 25,000개 → 99.5% 감소) |
| SVG 용량 | 약 3.9 KB |
| EPS / PDF | 약 5.2 KB / 4.6 KB |
| 원본 대비 시각 오차 | 평균 2.1/255 (픽셀당) |

## 2. 파이프라인

```
이미지 ─┬─ 배경 플러드필(가장자리/모서리) ─┐
        ├─ 팔레트: Median-Cut → K-means ────┤
        └─ 잡티 흡수(minArea) ──────────────┤
                                            ▼
                안티에일리어싱 혼합비 → 서브픽셀 멤버십 필드
                                            ▼
                Marching Squares 등고선 → 폐곡선 링크
                                            ▼
                Douglas–Peucker 단순화 → 코너 감지 → 3차 베지어 피팅
                                            ▼
                좌표 반올림 → 색상별 패스 병합 → SVG / EPS / PDF
```

### 2-1. 전처리

- **배경 투명화** — 가장자리(또는 네 모서리)에서 시작하는 플러드필. 시작 픽셀 색과의 거리만
  비교하므로, 로고 **안쪽**의 같은 색은 지우지 않습니다.
- **색상 양자화** — Median-Cut 으로 색 공간을 분할하고 K-means 로 중심을 정제합니다.
  - 점유율이 낮은 색은 분할 대상에서 제외 (`minSize`) → AA 잡색이 팔레트를 먹지 않음
  - **작은 강조색 구출**(`recoverColors`) — 로고의 빨간 점처럼 2% 정도의 색도 살려냅니다
  - **AA 혼합색 정리**(`pruneBlends`) — 두 색 사이(선분 위)에 놓인 저점유 색은 경계가 번진
    색으로 보고 가까운 쪽으로 합칩니다. 진짜 색은 선분 위에 없으므로 살아남습니다
- **잡티 제거** — 4-연결 성분 라벨링 후 `minArea` 미만 성분을 주변 다수 색에 흡수.
  삭제가 아니라 흡수라서 경계가 깨지지 않습니다.

### 2-2. 서브픽셀 윤곽

안티에일리어싱된 경계 픽셀은 두 색의 혼합입니다. 가장 가까운 두 팔레트 색까지의 거리 비율로
**커버리지(0~1)** 를 구하고, 그 값을 필드로 삼아 Marching Squares 로 0.5 등고선을 뽑습니다.
보간이 픽셀 격자 사이를 지나가므로 윤곽이 픽셀보다 정밀합니다.

배경을 지운 뒤에는 **알파 디컨타미네이션**을 합니다. 경계 픽셀을 `C = tF + (1-t)B` 로 보고
`t = (C-B)·(F-B)/|F-B|²` 를 알파에 반영해, 회색 테두리가 아니라 반투명 경계가 되게 합니다.

### 2-3. 곡선

- **Douglas–Peucker** 로 점을 줄이고 (슬라이더 0.2~3.0px)
- 꺾임각이 임계(기본 72°)보다 큰 점을 **코너**로 분리한 뒤
- 구간마다 **Schneider 최소제곱 3차 베지어** 피팅 (재매개변수화 + 오차 기반 분할)
- 한 직선 위의 점들은 `L` 하나로 (베지어 7개 숫자 → 2개)
- 좌표는 1~3자리로 반올림, 같은 색 패스는 하나의 `<path>` 로 병합

## 3. 내보내기 포맷

| 포맷 | 내용 | 쓰는 곳 |
|---|---|---|
| **SVG** | `viewBox` 정리, 색상별 `<g>`, `fill-rule="evenodd"`, 외부 참조 0 | 웹·피그마·일러스트레이터·레이저 커터 |
| **EPS** | `%!PS-Adobe-3.0 EPSF-3.0`, `%%BoundingBox`, `moveto/lineto/curveto/closepath/eofill` | 인쇄소 표준 |
| **AI** | PDF 1.4 벡터 스트림을 `.ai` 확장자로 저장 | Adobe Illustrator |
| **PDF** | PDF 1.4, 1페이지, 순수 벡터 | 시안·교정 공유 |

> **AI 파일 안내** — `.ai` 는 별도 전용 바이너리가 아니라, Illustrator 가 읽는 **PDF 호환 벡터
> 스트림**입니다. 열면 일반 벡터 오브젝트로 인식되고, 편집·저장도 그대로 됩니다.

EPS/PDF 의 CMYK 는 **프로파일 없는 단순 변환**(`K = 1 - max(R,G,B)`)입니다. 최종 인쇄 색은
인쇄소 RIP 에서 한 번 더 맞추세요. RNA(화면) 확인용으로는 RGB 그대로 쓰는 편이 정확합니다.

## 5. 테스트

```bash
# 엔진 (알고리즘·포맷·용량·보안) — 약 1초
node test.js

# 실제 브라우저 (1440×900 / 390×844)
LD_LIBRARY_PATH=/workspace/scratch/chromelibs:/workspace/scratch/calc/libs \
  python3 uitest.py
```

`test.js` 는 다음을 확인합니다.

- 팔레트: 3색 분리, k-means 오차 감소, 작은 강조색 보존
- 배경: 모서리 투명 · 내부 보존 · 안쪽 흰색 보존 · `mode=none` 무변경
- 잡티: 작은 섬 흡수 · 큰 면 유지
- 등고선: 폐곡선 · 픽셀 경계 좌표 · 면적(사각형 36, 원 πr²)
- 단순화: 점 감소 · 끝점 유지 · ε 준수
- 피팅: 원호는 전부 `C`, 사각형 코너는 `L`, 시작점 반환
- SVG: XML 구조 · viewBox · 외부 참조 0 · 소수점 자릿수
- EPS: 헤더 · BoundingBox · 연산자 · gsave/grestore · 7bit ASCII
- PDF: xref 오프셋 · 스트림 Length · 연산자 · MediaBox · CMYK
- 용량: 512px 2색 로고 SVG < 12KB, 앵커 < 250
- 경계: 단색 · 완전 투명 · 1×1 · 0크기 · 투명 PNG
- 보안: 민감정보 0건 · 실키 패턴 0건 · 외부 URL 0건 · fetch 0건

`uitest.py` 는 실제 크롬에서 다음을 확인합니다.

- 콘솔 에러 0 · 외부 요청 0 · 가로 넘침 0 (데스크톱/모바일)
- 샘플 3종 변환 → 노드·패스·용량 통계
- PNG 업로드 → 변환 → 슬라이더 조절 시 노드·용량 감소
- 100%/200%/400% 확대 비교 · 겹쳐보기 · 경로(노드) 보기
- **SVG 를 실제로 래스터화해 원본과 픽셀 비교** (평균 오차 기준)
- SVG/EPS/AI/PDF 다운로드 → 파일 헤더·구조·pypdf 파싱 검증
- C안 토큰(캔버스 #06070B · 글래스 .05/.11 · 바이올렛/민트 · 축소 투명도 폴백) · 모바일 레이아웃 · 라이트 모드 · 가이드 화면

## 6. 성능

| 입력 | 설정 | 시간 |
|---|---|---|
| 400×400 | 3색 · 기본 | 약 190 ms |
| 512×512 | 2색 · 기본 | 약 90 ms |
| 900×900 | 8색 · 기본 | 약 300 ms |
| 1200×1200 | 6색 · 기본 | 약 300 ms (maxSide 축소 포함) |

작업 해상도는 기본 1200px 로 줄여서 처리합니다(원본 비율 유지, viewBox 로 확대).
`maxSide` 를 1600 까지 올리면 더 정밀하지만 느려집니다.

## 7. 한계

- **사진**은 벡터화해도 사진처럼 보이지 않습니다. 색면 일러스트로 바뀝니다.
- **그라데이션**은 색 단계로 근사하므로 띠가 보일 수 있습니다.
- **아주 작은 글자**(12px 이하)는 뭉개집니다. 텍스트는 편집 프로그램에서 다시 입력하세요.
- **반투명 그림자**는 불투명 색면이 됩니다.
- CMYK 변환은 근사치입니다.

## 9. 디자인 시스템 — C안 Dark Glass Studio

화면의 기본값은 **다크 글래스**입니다. 라이트 모드는 헤더의 해·달 버튼으로 켜는 선택 옵션이며,
선택은 `localStorage`(`ovs.theme`)에 남습니다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--pm-canvas` | `#06070B` | 화면 바닥 |
| `--pm-glass` | `rgba(255,255,255,.05)` | 카드·패널 바탕 |
| `--pm-edge` | `rgba(255,255,255,.11)` | 카드 1px 보더 |
| `--pm-violet` | `#8B5CF6` | 상태·액션(활성 탭, 선택 칩, 경로) |
| `--pm-teal` | `#34E0C8` | 성공·수치(완료 상태, 노드 감소, 섹션 번호) |
| `--pm-opaque` | `#14151B` | 투명도 줄이기 폴백 |

- 글로우는 화면당 2~3개(상단 바이올렛, 우상단 민트, 하단 핑크)만 두고, 카드마다 넣지 않습니다.
- blur는 상단 바·패널 태그·토스트 같은 **짧은 크롬**에만 씁니다. 긴 목록·표는 불투명 배경입니다.
- `prefers-reduced-transparency: reduce` 또는 `data-transparency="reduce"`에서 유리면은 `#14151B`로,
  `backdrop-filter`는 해제됩니다. `prefers-reduced-motion: reduce`에서는 진행 바 애니메이션이 멈춥니다.
- 원본/벡터 비교 캔버스는 **투명 체커보드**가 기본이고, `흰 배경` 토글은 인쇄 확인용 흰 시트로 바뀝니다.
- 폰트는 로컬 woff2(PlexKR)만 사용하고 아이콘은 인라인 SVG입니다. 외부 요청은 0건입니다.
